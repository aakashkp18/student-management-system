# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some Oxlint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the Oxlint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and Oxlint's TypeScript related rules in your project.

# student-management-system
🎓 Student Management System

A simple and responsive Student Management System built using React.js. This project allows users to manage student records through a clean and user-friendly interface.

🚀 Features

- 🔐 Login page
- 📊 Dashboard with student information
- 👨‍🎓 View student records
- ➕ Add new students
- ✏️ Edit student details
- 🗑️ Delete student records
- 🔄 CRUD operations using Axios
- 🧭 Navigation using React Router
- 📱 Responsive user interface
- ⚡ API-based student data management

🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Axios
- React Router DOM
- Vite

⚙️ Installation & Setup

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project folder

cd Student_management_system

3. Install dependencies

npm install

4. Start the development server

npm run dev

The application will run on the local development server provided by Vite.

🔄 CRUD Operations

This project demonstrates the basic CRUD operations:

- Create – Add a new student
- Read – Display student records
- Update – Edit existing student details
- Delete – Remove a student record

Axios is used to communicate with the API.

🎯 Purpose of the Project

The main purpose of this project is to practice and demonstrate practical React.js concepts such as:

- Components
- Props
- State management using "useState"
- Side effects using "useEffect"
- React Router
- API integration
- Axios
- CRUD operations
- Form handling
- Dynamic rendering
